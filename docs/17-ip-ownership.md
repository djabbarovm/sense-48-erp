## 2. Что входит в продукт (объект права)

Продукт «Finance OS» — единый объект, состоящий из:

1. **Исходный код** — `apps/`, `packages/`, `scripts/`, конфигурация сборки и CI (`.github/`, `Dockerfile`, `docker-compose*.yml`, `Makefile`).
2. **Спецификация** — `docs/00…16`, `CLAUDE.md`, `MASTER_PROMPT.md`. Это основной творческий вклад автора: постановка продукта, бизнес-правила BR-001…BR-072, state machines, RBAC-матрица, экраны, acceptance-критерии.
3. **Архитектурные решения** — `DECISIONS.md` (ADR-001…), фиксирующие авторские выборы, не следующие из стека автоматически.
4. **Схема данных и миграции** — `packages/db/prisma`.
5. **Шаблоны миграции данных** — `templates/*.xlsx`.
6. **Тексты интерфейса** — i18n-словари (`ru.json`, `uz`, `en`).
7. **Синтетические seed-данные** — `packages/db/seed` (вымышленные компании Rooftop/Sense48/ORDO из `docs/10`).
8. **Название и товарный знак** — «Finance OS» (регистрация ТЗ — задача юристу, п. 6).

**Правило разделения (обязательно к соблюдению в коде):** ядро продукта (`packages/core`, `apps/web`) не содержит знаний о конкретном клиенте. Всё клиентское живёт в данных тенанта, в конфигурации или в зашифрованных файлах, и может быть удалено без потери работоспособности продукта. Тест на это — чистая установка c `pnpm seed` (синтетика) должна проходить все проверки.

## 5. Схема передачи в компанию

Целевая последовательность:

1. Регистрация юридического лица (форма, доли, устав — вне scope этого документа).
2. Договор об отчуждении исключительного права на программу для ЭВМ и сопутствующую документацию: от физического лица (автор) к компании. Альтернатива — внесение исключительного права в уставный капитал (требует оценки).
3. Акт приёма-передачи c перечнем объектов из раздела 2 и указанием commit-hash / тега репозитория на дату передачи.
4. Обновление `LICENSE`, раздела 1 этого документа и `package.json` (`author`) — отдельный коммит «передача права», помеченный git-тегом `ip-transfer-YYYY-MM-DD`.
5. Перенос репозитория в GitHub-организацию компании (сохраняет историю).
6. Если к этому моменту есть сотрудники/подрядчики — договоры c условием о служебном произведении / передаче прав на результат.

До завершения шагов 2–4 правообладателем остаётся физическое лицо. Клиентские договоры до этого момента заключаются от имени физического лица либо c последующей уступкой компании (решает юрист).

4. Сторонние библиотеки c copyleft-лицензиями (GPL, AGPL) не добавляются без ADR: они могут наложить обязательства на продукт при передаче/лицензировании.
